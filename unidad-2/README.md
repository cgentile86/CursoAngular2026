* Descripción breve del proyecto.
Se presenta una aplicación con un componente para registrar usuarios utilizando la temática vista en la clase 2 del curso de Angular.

Se implementaron directivas estructurales para manipular el DOM mediante *ngIf y @if y directivas de atributos o estilos mediante ngClass.

Este trabajo contiene un formulario reactivo implementado con el servicio de FormBuilder de Angular donde se utilizaron validadores y manejo de errores para informar al usuario las acciones a seguir para realizar una carga exitosa.


* Instrucciones para clonar, instalar dependencias (npm install) y ejecutar
Descargar este proyecto. Sobre la carpeta raiz (unidad-2) ejecutar en la terminal los siguientes comandos:
npm install
npm run start

Luego ver aplicación desde un navegador por http://localhost:4200/
