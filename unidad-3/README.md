* Descripción breve del proyecto.
En esta aplicación se implementa el concepto de Servicio para el encapsulamiento de la lógica de negocio. Junto con la creación y uso de Pipes estándares y personalizados donde se defininen las transformaciones de los datos para ser mostrados en un componente destinado a la consulta, creación (aleatoria) y borrado de Productos de un catálogo.

* Instrucciones para clonar, instalar dependencias (npm install) y ejecutar
Descargar este proyecto. Sobre la carpeta raiz (unidad-3) ejecutar en la terminal los siguientes comandos:
npm install
npm run start

Luego ver aplicación desde un navegador por http://localhost:4200/
